# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Antigravity Proxy** seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Please report security issues privately via [GitHub Security Advisories](https://github.com/kqlio67/agy-proxy/security/advisories/new) or contact repository maintainers directly.
3. Include detailed steps to reproduce the vulnerability, along with any relevant proof-of-concept code.

---

## What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will assess the impact and work on a fix in a private branch.
- **Resolution & Disclosure:** Once a fix is released in a new version, we will coordinate public disclosure and credit you for the discovery.
