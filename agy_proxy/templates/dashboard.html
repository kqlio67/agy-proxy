Account Pool Routing & Load Balancing

Control how API and IDE requests are distributed across active accounts in your pool.

Primary
Primary Priority

Routes all traffic to the designated Primary account. Transparently fails over to secondary pool accounts only if 429 quota exhaustion occurs.

Best for: stable session history
Round-Robin Rotation

Evenly rotates each incoming request across all enabled accounts in round-robin sequence. Maximizes concurrent throughput and prevents single-account quota burn.

Best for: heavy team / multi-client usage
Balanced (Least Used)

Routes traffic dynamically to the account with the lowest total request count and oldest last-used timestamp. Balances load adaptively over rolling quota windows.

Best for: preserving rolling 5h reset buffers
