# 💻 Google Antigravity CLI (`agy`) & ACP Stdio Server Guide

`agy-proxy` provides first-class, seamless integration for **Google Antigravity CLI** (`agy` v1.5.5+), allowing you to run the official command-line coding agent or start the **Agent Client Protocol (ACP)** stdio server routed transparently through your proxy pool.

---

## 📋 Overview & Architecture

The Antigravity CLI binary (`agy`) is a stripped 247 MB Go ELF/Mach-O executable built with Google's internal toolchain (`Go 1.28-RC00`, `boringcrypto`, `simd`, `tcmalloc`).

Through deep reverse-engineering of `agy` v1.5.5, `agy-proxy` unlocks:
- **`CLOUD_CODE_URL` Routing**: CLI Go runtime natively honors `CLOUD_CODE_URL=http://127.0.0.1:8000`, rerouting all internal AI requests and model listings through the proxy without modifying binary files.
- **Account Selection (`AGY_ACCOUNT`)**: Target specific Google accounts from your multi-account pool per CLI session.
- **Autonomous Execution**: Full access to reasoning effort (`--effort max`), agent modes (`--mode auto|accept-edits|plan`), and auto-approval (`--danger`).
- **ACP Stdio Server**: Dedicated Agent Client Protocol server connecting **Zed**, **Neovim**, **Emacs**, or **Cursor** to Antigravity as an intelligent coding subagent.
- **Context Compactor & Telemetry Control**: Injects `AGY_CLI_AUTO_COMPACT_OVERRIDE` and sets `ANTIGRAVITY_CLI_TELEMETRY=0`.

## 🚀 Quick Usage

### 1. Launching Antigravity CLI (`agy-proxy agy`)

Run the CLI in autonomous or interactive mode, with all requests managed by `agy-proxy`:

```bash
# Autonomous mode with default proxy account:
agy-proxy agy --mode auto

# Plan mode with maximum reasoning effort:
agy-proxy agy --mode plan --effort max

# Select a specific pooled account:
agy-proxy agy -a user@example.com --mode auto

# Autonomous execution with permission auto-approval:
agy-proxy agy --mode auto --danger

# Force enable CLI auto-compaction:
agy-proxy agy --auto-compact

# Pass prompts or files directly to the agent:
agy-proxy agy -p "Analyze git status and optimize build configuration"
```

### 2. Available Models & Subcommands

All built-in subcommands of the `agy` binary are fully supported and routed through `agy-proxy`:

```bash
# List available models via proxy CloudCode API:
agy-proxy agy models

# Inspect release notes and changelog:
agy-proxy agy changelog

# Manage native CLI MCP servers:
agy-proxy agy mcp list
agy-proxy agy mcp add my-mcp-server

# Manage plugins:
agy-proxy agy plugin list
```

## ⚡ Agent Client Protocol (ACP) Stdio Server

The **Agent Client Protocol (ACP)** is an open stdio JSON-RPC protocol allowing code editors to communicate with external AI coding agents. `agy-proxy acp` starts `agy` in ACP server mode with clean stdio stream preservation (no terminal formatting to corrupt JSON-RPC).

### Running ACP Server:

```bash
# Start standard ACP stdio server:
agy-proxy acp

# Start ACP server with specific account and auto-approved permissions:
agy-proxy acp -a user@example.com --danger
```

### Editor Integration Examples

#### 1. Zed Editor (`~/.config/zed/settings.json`)

Configure Zed to use Antigravity as an external agent via ACP:

```json
{
  "agent": {
    "provider": "acp",
    "command": "agy-proxy",
    "args": ["acp", "--danger"]
  }
}
```

#### 2. Neovim (`avante.nvim` or `codecompanion.nvim`)

Configure Neovim's ACP agent provider to connect directly:

```lua
require("codecompanion").setup({
  adapters = {
    antigravity_acp = function()
      return require("codecompanion.adapters").extend("acp", {
        command = { "agy-proxy", "acp", "--danger" },
      })
    end,
  },
  strategies = {
    chat = { adapter = "antigravity_acp" },
    inline = { adapter = "antigravity_acp" },
  },
})
```

## 🛠️ Direct Executable Wrapper (`~/.local/bin/agy-proxy-exec`)

If you want a standalone shell executable that immediately executes `agy` through `agy-proxy` without typing `agy-proxy agy`, generate the non-destructive wrapper:

```bash
# Install desktop & CLI wrappers:
agy-proxy patch launcher --install

# Check installation status:
agy-proxy patch launcher
```

This creates `~/.local/bin/agy-proxy-exec`:
```bash
#!/usr/bin/env bash
# Antigravity CLI Proxy Runner (generated by agy-proxy)
export CLOUD_CODE_URL="http://127.0.0.1:8000"
export ANTIGRAVITY_VSCODE_HOST=1
export ANTIGRAVITY_CLI_TELEMETRY=0
exec "/home/user/.local/bin/agy" "$@"
```

> [!IMPORTANT]
> The original `/home/user/.local/bin/agy` executable is **never overwritten or modified**. The wrapper exists side-by-side as `agy-proxy-exec`.

## 📑 CLI Option Reference

| Option | Flag Alias | Description |
| :--- | :--- | :--- |
| `--port` | `-p` | Local proxy server port (default: `8000`). |
| `--url` | | Custom proxy URL (e.g. `http://127.0.0.1:8000`). |
| `--account` | `-a` | Target account ID or email from the account pool (sets `AGY_ACCOUNT`). |
| `--mode` | `-m` | Execution mode: `auto` (autonomous), `accept-edits` (confirm tools), `plan` (planning only). |
| `--effort` | `-e` | Reasoning effort: `low`, `medium`, `high`, `xhigh`, `max`. |
| `--danger` | `--dangerously-skip-permissions`, `--yolo` | Auto-approve all tool permission requests. |
| `--auto-compact` | | Force enable CLI auto-compaction (`AGY_CLI_AUTO_COMPACT_OVERRIDE=1`). |
| `--no-auto-compact` | | Disable CLI auto-compaction (`AGY_CLI_AUTO_COMPACT_OVERRIDE=0`). |
| `-t, --target, --bin` | | Explicit path to `agy` CLI binary. |
| `[args...]` | | All extra subcommands, flags, prompts, or files are passed directly to `agy`. |

## 🌐 Environment Variables Reference

When invoking `agy-proxy agy` or running `agy` manually in your shell, the following environment variables control routing and behavior:

| Variable | Recommended Value | Effect |
| :--- | :--- | :--- |
| `CLOUD_CODE_URL` | `http://127.0.0.1:8000` | Redirects all CloudCode API calls to `agy-proxy`. |
| `AGY_ACCOUNT` | `<email or account ID>` | Selects which identity from the pool is active. |
| `AGY_CLI_AUTO_COMPACT_OVERRIDE` | `1` or `0` | Controls internal context compaction behavior. |
| `ANTIGRAVITY_VSCODE_HOST` | `1` | Enables IDE host interaction hooks. |
| `ANTIGRAVITY_CLI_TELEMETRY` | `0` | Disables telemetry reporting to Google. |
| `AGY_CLI_BIN` | `/path/to/agy` | Custom override path for the `agy` binary. |
